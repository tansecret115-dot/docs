KoboldCPP Colab Modded is a modified Google Colab notebook built on top of [KoboldCpp](https://github.com/LostRuins/koboldcpp), an open-source LLM inference engine. It lets you run large language models, image generators, vision models, text-to-speech engines, music generators, and embedding models directly in Google Colab's cloud GPU environment — completely free, with no local hardware, no installation, and no technical setup required. A built-in Cloudflare tunnel gives you a public URL the moment the model finishes loading, so you can connect from any device or compatible app.

## What you can do

KoboldCPP Colab Modded supports a broad range of AI model types. Every category has curated preset templates that are pre-configured and ready to run.

## How it works

The notebook is designed to be as simple as possible. You do not need to understand the underlying infrastructure — just press play twice and you are connected.

<Steps>
  <Step title="Cell 1 — Keep-alive (optional)">
    The first cell plays a silent audio loop to prevent mobile browsers from throttling the background tab. You only need to run this cell if you are on a phone or tablet.
  </Step>
  <Step title="Cell 2 — Model launcher">
    The second cell contains all the configuration options. Select a preset template from the dropdown (or configure a custom model manually by checking one of the loader checkboxes), then press the play button. Colab allocates a GPU, downloads the model weights via aria2, and starts the KoboldCpp server.
  </Step>
  <Step title="Connect via the Cloudflare tunnel URL">
    Once the server is running, a Cloudflare tunnel URL appears at the bottom of the cell output. Copy that URL and open it in your browser or paste it into a compatible front-end app. The URL is unique to your session and changes each time you restart.
  </Step>
</Steps>

<Note>
  Keep the Colab tab open in your browser for the entire session — closing or navigating away from it will eventually cause the runtime to shut down. Check back occasionally, as Google may display a captcha to verify you are still present.
</Note>

## The two notebooks

KoboldCPP Colab Modded provides two notebook variants depending on your needs and Colab plan.

| Notebook | File | Best for |
|---|---|---|
| **Standard** | `colab.ipynb` | Free Colab tier with a T4 GPU. Suitable for most language models up to ~13B parameters and smaller image models. |
| **L4 GPU** | `colabL4.ipynb` | Colab Pro or Pro+ with an L4 GPU. Better performance for larger models, higher-resolution image generation, and memory-intensive workloads. |

Both notebooks share the same preset template library and configuration interface. Start with the standard notebook and switch to the L4 variant if you need more VRAM or faster inference.

## Requirements

KoboldCPP Colab Modded has minimal requirements — you do not need a powerful computer or any special software.

- **A Google account** — needed to access and run Google Colab notebooks.
- **A modern web browser** — Chrome, Firefox, Safari, and Edge all work. The Cloudflare tunnel URL is accessible from any device with an internet connection.

That is it. Colab provides the GPU, storage, and compute. You just bring the browser.
