KoboldCPP Colab Modded is a modified Google Colab notebook that lets you run powerful AI models — including large language models, image generators, vision models, speech synthesis, and music generation — entirely in the cloud using Google Colab's free GPU resources. There is nothing to install and no expensive hardware required: just open the notebook, pick a model, press play, and connect through the Cloudflare tunnel URL that appears in the output.

## How to get started

You can go from zero to a running AI model in four steps. No account setup, no configuration files, and no command line required.

<Steps>
  <Step title="Open the notebook in Colab">
    Click the **Open in Colab** link to load the KoboldCPP Colab Modded notebook directly in your browser. Sign in with your Google account if prompted.
  </Step>
  <Step title="Pick a model">
    In the model cell, select a preset template from the dropdown menu. Each named template automatically configures the right context size, quantization, and launch flags for that model.
  </Step>
  <Step title="Click play">
    Press the play button on the model cell and wait while Colab downloads the model weights and starts the KoboldCpp server. Download time depends on model size and Colab's current network speed.
  </Step>
  <Step title="Connect via the Cloudflare URL">
    Once startup is complete, a Cloudflare tunnel URL appears at the bottom of the cell output. Copy that URL and open it in any browser or compatible app to start chatting.
  </Step>
</Steps>
