Context size determines how many tokens — roughly words or subwords — the model can process in a single request. A larger context lets you hold longer conversations, feed in more document text, or write extended stories without the model "forgetting" earlier content. Choosing the right value is a balance between capability and the VRAM available on Colab's GPU.

## Available Values

| Tokens | Typical use |
|--------|-------------|
| 4096   | Short chat, quick Q&A |
| 8192   | General-purpose conversations |
| 12288  | Medium-length documents |
| 16384  | Longer chats and vision models (e.g. Gemma4) |
| 24576  | Extended creative writing |
| 32768  | Long documents, stories, and vision models (e.g. Qwen3-VL) |
| 49152  | Very long contexts |
| 65536  | Maximum context for supported models |

You can also type any custom integer directly into the **ContextSize** field if none of the presets suit your needs.

## How to Set Context Size

Find the **ContextSize** dropdown in the notebook's form cell, select your desired value (or type a custom number), then play the cell to apply it.

<Info>
Preset templates automatically configure an optimal context size for their bundled model. You only need to change this setting when you are loading a custom model.
</Info>

<Warning>
Larger context sizes consume significantly more VRAM. If the model fails to load or the Colab session crashes immediately after launch, try reducing the context size — for example, drop from 32768 to 16384 or 8192.
</Warning>

## Recommended Context Sizes by Use Case

| Use Case | Recommended Context |
|----------|---------------------|
| Short chat / Q&A | 4096 |
| General use | 8192–16384 |
| Long documents / stories | 32768–65536 |
| Vision models (Gemma4) | 16384 |
| Vision models (Qwen3-VL) | 32768 |

## Deleting Cached Models Between Runs

The notebook includes a **DeleteExistingModels** checkbox (default: **on**). When enabled, it deletes all `*.gguf`, `*.bin`, and `*.ggml` files from the Colab workspace before downloading and starting the new model. This prevents stale model files from filling up Colab's ephemeral disk space when you switch between models or context-size configurations.

<Note>
If you are repeatedly restarting the same model and want to avoid re-downloading it each time, uncheck **DeleteExistingModels**. The previously downloaded file will be reused, which can save several minutes per restart.
</Note>
