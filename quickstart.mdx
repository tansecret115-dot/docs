Getting started with KoboldCPP Colab Modded takes just a few clicks. You open the notebook in Google Colab, select a model preset from the dropdown, press play, and within minutes you have a fully running AI accessible through a Cloudflare tunnel URL — no installation, no configuration files, and no local GPU required.

<Steps>
  <Step title="Open the notebook in Google Colab">
    Click the link below to open the KoboldCPP Colab Modded notebook directly in your browser. Sign in with your Google account if you are not already signed in.

    [**Open colab.ipynb in Google Colab →**](https://colab.research.google.com/github/tansecret115-dot/KoboldCPP-Colab-Modded/blob/main/colab.ipynb)
  </Step>
  <Step title="Run the keep-alive cell (mobile only)">
    If you are on a phone or tablet, run the first cell labelled **"Tap this if you play on Mobile"**. It plays a silent audio loop that prevents your mobile browser from throttling the background tab and shutting down the session. Desktop users can skip this step.
  </Step>
  <Step title="Choose a model preset">
    In the second cell, find the **Template** dropdown and select a preset. Each named template auto-configures the optimal context size, quantization, and launch flags for that model.

    The default template is:

    > **GLM-4.7-Flash-REAP** — MoE architecture, 23B-A3B parameters, Q3\_K\_S quantization, 10.3 GB

    To load your own model instead, check one of the loader checkboxes below the Template dropdown (such as **LoadTextModel**). Checking any loader checkbox activates manual mode and overrides the selected template, letting you specify your own model URL, context size, and other settings.
  </Step>
  <Step title="Click play and wait for the model to load">
    Press the **play button** (▶) on the model cell. Colab will allocate a GPU, install dependencies, download the model weights, and start the KoboldCpp server. Progress messages appear in the cell output as each step completes. Download time varies by model size and Colab's current network speed — most presets are ready in one to three minutes.
  </Step>
  <Step title="Copy the Cloudflare URL and connect">
    When startup is complete, a line like the following appears at the bottom of the cell output:

    ```text
    https://your-unique-id.trycloudflare.com
    ```

    Copy that URL and open it in your browser. You can also paste it into any KoboldCpp-compatible front-end app. Your AI session is live.
  </Step>
</Steps>

<Info>
  Named preset templates automatically configure optimal context size, quantization level, and KoboldCpp launch flags for that specific model. You do not need to adjust any settings manually when using a preset.
</Info>

<Warning>
  Google Colab provides a limited amount of free GPU time per day. Keep the Colab tab open and active for your entire session — closing it may terminate the runtime. Respond to any captcha prompts that Colab displays to confirm you are still present, or the session may be interrupted.
</Warning>

<Note>
  The **Delete Existing Models** checkbox is enabled by default. Each time you restart the cell, all previously downloaded model files are deleted and re-downloaded fresh. Uncheck this option if you want to reuse models cached from a previous run in the same Colab session.
</Note>
