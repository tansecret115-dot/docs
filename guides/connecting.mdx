After KoboldCpp finishes downloading and starting up, it automatically creates a Cloudflare tunnel and prints a public HTTPS URL in the cell output. This URL is your gateway to both the KoboldCpp web chat interface and its OpenAI-compatible API — accessible from any device with a browser, no VPN or port forwarding required.

## Finding Your Tunnel URL

<Steps>
  <Step title="Wait for startup to complete">
    After clicking play, the cell will download the KoboldCpp binary and your chosen model, then launch the server. This process typically takes **1–3 minutes** depending on model size and Colab's network speed. Do not interrupt the cell during this time.
  </Step>
  <Step title="Scroll to the bottom of the cell output">
    Once the cell is running, click inside the output area and scroll all the way to the bottom. The tunnel URL is printed near the end of the startup log, after the server has successfully initialized.
  </Step>
  <Step title="Locate the Cloudflare URL">
    Look for a line containing a `trycloudflare.com` address. It will look something like:

    ```
    https://some-random-words.trycloudflare.com
    ```
  </Step>
  <Step title="Open the URL">
    Click or copy that URL and open it in your browser. It will load the KoboldCpp web UI where you can start chatting immediately.
  </Step>
</Steps>

<Info>
  The tunnel URL is randomly generated each time you start or restart the session. Bookmark it for the current session only — you'll get a new URL next time.
</Info>

## OpenAI-Compatible API

The same base URL also exposes a fully OpenAI-compatible REST API at the `/v1/` path. You can point any OpenAI-compatible client, extension, or tool at your tunnel URL without any additional setup.

For example, to send a chat completion request:

```bash
curl https://autumn-pine-3842.trycloudflare.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "koboldcpp", "messages": [{"role": "user", "content": "Hello!"}]}'
```

Replace `autumn-pine-3842.trycloudflare.com` with the actual URL from your cell output. The full completions endpoint is:

```
https://autumn-pine-3842.trycloudflare.com/v1/chat/completions
```

## LocalTunnel Fallback

If Cloudflare is unavailable or the tunnel fails to connect, you can enable the **MakeLocalTunnelFallback** option in the notebook form. When this is enabled, the notebook uses [localtunnel](https://localtunnel.me/) as an alternative tunnel provider.

After enabling MakeLocalTunnelFallback and re-running the cell:

1. A `loca.lt` URL will appear in the cell output.
2. When you open that URL in your browser, you'll be prompted for a password.
3. The password is retrieved automatically and printed in the cell output. You can also find it at [loca.lt/mytunnelpassword](https://loca.lt/mytunnelpassword) if you need it independently.

<Note>
  Your tunnel URL is public and accessible to anyone who has it. Since it is randomly generated it is effectively private by default, but you should still avoid sharing it if you don't want others accessing your session.
</Note>
